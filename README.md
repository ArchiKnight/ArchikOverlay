# ArchikOverlay

**Оверлеи виджетов поверх всех окон — для стримеров.**  
Донаты, подписки, MemeAlert и любые веб-виджеты прямо поверх игры. Особенно если у вас один монитор.

---

## ⬇️ Скачать

Перейдите в раздел **[Releases](../../releases/latest)** и скачайте последний `ArchikOverlay.exe`.

- **Один файл.** Никаких установщиков, зависимостей и Python.
- **Windows 10 / 11** (64-bit).
- Просто запустите `ArchikOverlay.exe` — и всё.

> При первом запуске Windows SmartScreen может показать предупреждение (файл без цифровой подписи). Нажмите **«Подробнее» → «Выполнить в любом случае»**.

---

## Что это

ArchikOverlay создаёт **прозрачные окна поверх всех приложений** с **кликами сквозь них**. Вы добавляете ссылку на виджет (страницу донатов, MemeAlert, StreamElements, Streamlabs, DonationAlerts и т.п.), настраиваете размер, позицию, прозрачность, громкость и масштаб — и окно висит поверх игры, не мешая управлению.

Можно держать открытыми сколько угодно виджетов одновременно. Настройки применяются мгновенно, без перезапуска.

---

## Зачем это нужно

- **Стримеры с одним монитором** — видят донаты, подписки, мемы и алерты прямо поверх игры, не переключаясь на второй экран.
- **Стримеры с двумя мониторами** — часто пропускают мемалерты и донаты, потому что смотрят в игру, а не на второй экран. С ArchikOverlay уведомление появляется **на основном мониторе поверх игры**, и его невозможно пропустить.

---

## Возможности

- 🪟 **Прозрачные окна поверх всех приложений** с кликами сквозь них.
- 🎨 **Настройка каждого виджета**:
  - URL или локальный HTML-файл
  - Размер (W × H) и позиция (X, Y)
  - Масштаб страницы (10–200%)
  - Прозрачность (10–100%)
  - Громкость (0–100%)
  - Кастомный CSS для скрытия лишних элементов страницы
  - Рамка вокруг окна (для настройки позиции)
- 📋 **Список виджетов** с управлением порядком наложения виджетов (выше/ниже), запуском/остановкой и редактированием.
- 🖥️ **Сворачивание в трей** — менеджер не мешает во время стрима.
- 🌐 **Два языка интерфейса** — русский и английский.

## Быстрый старт

1. Скачайте `ArchikOverlay.exe` из раздела **[Releases](../../releases/latest)**.
2. Запустите `ArchikOverlay.exe`.
3. Нажмите **«+ Создать виджет»**.
4. Вставьте ссылку на ваш виджет (например, страницу донатов или MemeAlert).
5. Настройте размер, позицию, прозрачность и громкость.
6. Нажмите **«▶ Запустить»**.

Готово — окно виджета висит поверх игры.

## Системные требования

| Параметр | Минимум |
|---|---|
| ОС | Windows 10/11 |
| Архитектура | x64 |
| ОЗУ | 2 ГБ (рекомендуется 4+) |
| Место на диске | ~200 МБ (один exe + кэш WebEngine) |

> Кэш WebEngine хранится в `%LOCALAPPDATA%\ArchikOverlay\webengine`. Его можно безопасно удалить при закрытой программе — он пересоздастся.

## Частые вопросы (FAQ)

**Антивирус ругается на exe.**  
Файл собран через PyInstaller и не имеет цифровой подписи. Это нормально для open-source утилит. Если не доверяете — не запускайте. Добавить в исключения можно через «Защитник Windows» → «Исключения».

**Можно ли использовать локальные HTML-файлы?**  
Да. В редакторе виджета нажмите 📂 и выберите `.html` файл.

**Куда сохраняются виджеты?**  
`%LOCALAPPDATA%\ArchikOverlay\widgets.json` + хранение ссылок в реестре .
